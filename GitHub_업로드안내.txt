GitHub 업로드 방법

1. 이 ZIP 파일을 모두 풀어 주세요.
2. index.html과 dist 폴더를 GitHub meth 저장소의 같은 위치에 덮어쓰세요.
3. 배포가 완료되면 https://cnlegolab-spike.github.io/meth/ 에 접속하세요.
4. 이전 화면이 보이면 Ctrl + F5로 새로고침하세요.

학생 계정 생성은 반드시 위 온라인 주소에서 사용하세요.
컴퓨터의 index.html을 더블클릭한 화면에서는 계정 생성 요청이 차단됩니다.

이번 파일에는 오답 문항별 코멘트, 엑셀 내보내기, 학생 삭제,
40일 날짜 일정, 미완료 학습 팝업과 랭킹 화면 코드가 포함되어 있습니다.
랭킹 데이터 공개는 아직 승인 대기 상태이므로 서버에서 활성화되지 않았습니다.
계정 비밀번호는 기존 Supabase에 설정한 비밀번호를 사용합니다.
